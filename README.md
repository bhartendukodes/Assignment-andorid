# Android Assignment

An Android application built with Kotlin, demonstrating core Android development concepts and best practices.

## Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM
- **UI:** Material Design / XML Layouts

## Getting Started

1. Clone the repository
```
git clone https://github.com/bhartendukodes/Assignment-andorid.git
```
2. Open in Android Studio
3. Build and run
